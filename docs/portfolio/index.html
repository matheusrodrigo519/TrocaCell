05 / DÚVIDAS FREQUENTES

Antes de começar, vale saber.

Preciso já ter uma identidade visual? +

Não. Podemos partir das referências, cores e materiais que você já tem e definir uma direção visual para o site.

O site funciona no celular? +

Sim. A interface é planejada para funcionar bem em diferentes tamanhos de tela, incluindo celulares e computadores.

Hospedagem e domínio estão incluídos? +

Isso depende do projeto. Podemos usar opções de hospedagem compatíveis com a solução e alinhar previamente eventuais custos de domínio, serviços e manutenção.

Consigo atualizar os conteúdos depois? +

Sim, quando o projeto prevê essa necessidade. Podemos avaliar um painel de edição ou um formato de manutenção conforme a frequência das alterações.

Quanto tempo leva e quanto custa? +

O prazo e o orçamento dependem das páginas, funcionalidades e materiais disponíveis. Depois de entender sua ideia, apresento uma proposta clara.
